DuoDesk

폴더블 폰을 노트북처럼 반쯤 접으면 위에는 내 컴퓨터 화면, 아래에는 맥과 같은 배열의 자판. 화면은 손가락으로 바로 누르는 원격 데스크톱 앱입니다.

연결 준비

맥 — 화면 공유(설치 없음)
시스템 설정 › 일반 › 공유 › 화면 공유를 켜고, 앱에는 맥 로그인 이름과 맥 암호를 넣으세요.
윈도우·리눅스
VNC 서버(TightVNC 등)를 설치하고 VNC 암호를 넣으세요.
밖에서(원격)
앱 홈의 'Tailscale로 로그인'으로 컴퓨터와 같은 Tailscale 계정에 로그인하면 내 컴퓨터 목록이 나옵니다. 컴퓨터에도 Tailscale이 켜져 있어야 합니다.
같은 와이파이(로컬)
같은 네트워크의 컴퓨터는 자동으로 찾습니다. 암호화·중계 없이 바로 붙어 가장 빠릅니다.

자주 묻는 것

화면 공유에 '인증 실패'가 떠요.
맥 로그인 이름(예: 홈 폴더 이름)과 맥 암호를 넣었는지 확인하세요. 이름을 비우면 맥에서 따로 켠 'VNC 암호'로만 붙습니다.
한글은 어떻게 쓰나요?
한/A 키를 짧게 누르거나 🌐fn을 혼자 누르면 한글·영문이 바뀝니다. 맥 화면 공유에서는 앱이 한글을 조합해 보내므로 맥 입력 소스와 상관없이 입력됩니다.
바깥 화면 덮개가 뭔가요?
설정 › 바깥 화면에서 켜면 펼친 채 바깥 화면에 노트북 덮개를 띄웁니다. iOS가 이때 카메라를 켜 두도록 요구해서 카메라 권한을 묻습니다. 영상은 저장하거나 보내지 않습니다.
